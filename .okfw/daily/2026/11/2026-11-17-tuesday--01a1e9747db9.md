## Learned
- `nasa-lint.py` reads `src/**/*.zig` only. On semscope it reports zero functions, so it gates nothing.
- `ste-check.py` skipped `PLAN.md`: an unclosed `markdown` fence at line 5 hid the whole plan.
- zmake reads the ZMakefile even with `--legacy`. Use `zmake -f Makefile` to run the Makefile.
- Go forbids import cycles, so recursion through direct calls stays inside one package.
- A top-level embedding of `#Ruleset` in a source file does not close the rules. Unify each source with the `#Ruleset` value.
- Two different CUE defaults cancel each other. The schema has no defaults for `enabled` and `severity`.
- `ste-check.py` exits 0 on warnings. The gate now runs it with `--strict`.
- An assertion must never check the shape of input. Two early assertions in the C adapter did, and a valid `while ( (1))` could trip one.
- gofmt moves `//go:embed` to the end of a doc comment, so a suppression comment above an embedded variable goes on the variable line.
- `golang.org/x/tools` v0.52.0 needs Go 1.26. The module already had `go 1.26.10`, so the README now says Go 1.26.
- The type-aware self-scan found no drop in semscope, because golangci-lint (errcheck) already checks the code. A probe file with `os.Remove("x")` gave one finding.
- The Zig standard library gave a semscope panic: an assertion checked the shape of input. The grammar parses `for ((n - 1)..m)` as a call without a name.
- `tree-sitter-zig` v1.1.2 lags Zig 0.17. It parses the identifier `await` as a keyword.
- A regex oracle on real code gives classes of defects with many instances. A class record with an exact count keeps the test strict.
- No `tree-sitter-zig` release reads Zig 0.17. Upstream master still reserves `async` and `await`.
- The generator ran with `tree-sitter-cli` 0.25.10 and wrote ABI 14. The go-tree-sitter 0.25 runtime reads it.
- The grammar binds a prefix operator to the callee: `?Span(T)` is a call of `nullable_type`.
- Zig 0.15 writes asm clobbers as a struct literal. The grammar reads strings only (ISSUE-009).
