## Learned
- `nasa-lint.py` reads `src/**/*.zig` only. On semscope it reports zero functions, so it gates nothing.
- `ste-check.py` skipped `PLAN.md`: an unclosed `markdown` fence at line 5 hid the whole plan.
- zmake reads the ZMakefile even with `--legacy`. Use `zmake -f Makefile` to run the Makefile.
- Go forbids import cycles, so recursion through direct calls stays inside one package.
- A top-level embedding of `#Ruleset` in a source file does not close the rules. Unify each source with the `#Ruleset` value.
- Two different CUE defaults cancel each other. The schema has no defaults for `enabled` and `severity`.
- `ste-check.py` exits 0 on warnings. The gate now runs it with `--strict`.
- An assertion must never check the shape of input. Two early assertions in the C adapter did, and a valid `while ( (1))` could trip one.
- gofmt moves `//go:embed` to the end of a doc comment, so a suppression comment above an embedded variable goes on the variable line.
