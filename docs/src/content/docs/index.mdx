import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

```console
$ semscope scan .
-: error: NASA-P10-05: go: 0 assertions in 2 functions (average 0.00, min 2)
main.go:5:5: error: NASA-P10-06: package variable `counter`
main.go:7:1: error: NASA-P10-01: recursion: walk -> walk
main.go:15:2: error: NASA-P10-02: `for` loop without a condition
semscope: 4 finding(s) in 1 file(s): 4 error(s), 0 warning(s), 0 note(s)
```

<CardGrid>
	<Card title="Composable CUE rulesets" icon="puzzle">
		A ruleset is a CUE value. The loader unifies a base ruleset with each overlay in sequence.
		The `--set` and `--omit-rule` flags tune the result on the command line.
	</Card>
	<Card title="Seven languages, one engine" icon="seti:config">
		Tree-sitter parses Go, C, C++, Zig, Python, Rust and C#. One adapter for each
		language gives the checks a flat record of the file.
	</Card>
	<Card title="NASA Power of 10" icon="approve-check">
		The built-in ruleset `nasa-p10` holds the ten NASA/JPL rules for safety-critical code.
		Two oracle scripts define the parity of six rules.
	</Card>
	<Card title="SARIF 2.1.0 and 2.2" icon="document">
		semscope writes text, JSON or SARIF. It validates each SARIF report against its JSON schema before it writes the report.
	</Card>
</CardGrid>
